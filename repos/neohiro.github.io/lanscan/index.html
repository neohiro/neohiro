Get the app

standalone builds · no Python needed

This page only renders what the LANScan service reports — browsers are sandboxed and cannot send ARP or ICMP. Download the standalone build for your platform, run it on the machine you want to inspect, then point this page at 127.0.0.1 below. It binds loopback only, so the snapshot is not reachable from your LAN.
