# ClockWidget

[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgray.svg)](https://github.com/)
[![Build Status](https://github.com/neohiro/ClockWidget/actions/workflows/release.yml/badge.svg)](https://github.com/neohiro/ClockWidget/actions)

A customizable, lightweight desktop clock widget with world clocks support.

<img width="433" height="178" alt="image" src="https://github.com/user-attachments/assets/0f18208f-dd97-4350-aebd-20be75ea025b" />

## Features
- **Always on Top:** Keeps the clock visible above other windows.
- **World Clocks:** Easily add multiple time zones to keep track of global times.
- **Customization:** Modify colors, transparency, and fonts directly from the settings menu.
- **System Tray:** Minimizes to the system tray for a clean desktop.
- **Auto-Start:** Option to launch automatically when your computer starts.

## Installation
You can download the compiled standalone executable for your operating system from the Releases tab.

If you prefer to run from source, install the requirements:
```bash
pip install pytz pystray Pillow
python desktop-widget.PY
```
